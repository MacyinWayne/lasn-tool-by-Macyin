# 篮球少女：飞跃巅峰 · 数值/配队工具包

一个**完全离线**的网页工具（纯 HTML/JS，无 CDN、无后端），用于：

- 球员图鉴 / 角色档案（成长方向、推荐属性、A层满级六维、防守建议、位置技能卡类型、技能说明）
- 养成配队（场景 / 方向 / 适配度 / 方案保存 / 心愿事件）
- 实战适配（5 位置星级、体格对位、器材 T 表、战术适配）
- 实战配队（PVP 三阵、圣山队伍配置、杯赛）
- 笔记养成（主养角色搭配、配套笔记角色、合成/修订规则）

## 在线使用（GitHub Pages）

1. 把本仓库内容推到 GitHub（public）；
2. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → Branch `main` / `(root)` → Save；
3. 等 1 分钟左右，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可。

## 本地使用

- 直接双击 `index.html`（Chrome/Edge）；
- 或 `python -m http.server 8000` 后访问 `http://localhost:8000`。
